# Orbis

A complete Class 9–10 study lab in a single web app — **96 interactive experiments and visual lessons**, all running in the browser with pure HTML, CSS and JavaScript. No build step, no dependencies.

## Subjects

| Subject | Activities |
|---|---|
| Physics | 29 |
| Chemistry | 25 |
| Biology | 16 |
| Mathematics | 13 |
| Social Science | 7 |
| Computer Science | 6 |

## Every activity includes

- A realistic, interactive simulation or visualisation with live readings
- Aim, apparatus/materials and a step-by-step procedure
- Precautions/safety notes where the real practical needs them
- A formula/rule box and a recordable observation table
- A closing **"The whole process, explained"** card — what happens and why, in plain words

Plus a live search bar across the whole library and a built-in offline assistant.

## Run it

Open `index.html` in any modern browser — that is the entire install. It also works offline once loaded.
