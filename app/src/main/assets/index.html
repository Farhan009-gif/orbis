Before you start — lab safety

Wear safety glasses for chemicals and heat. Never taste anything in the lab. Point heated test tubes away from people. If glass breaks or liquid spills, tell your teacher first — then clean up. These simulations are for learning; always follow your teacher in the real lab.

      Your providers

      No built-in list — add any OpenAI-compatible endpoint yourself. Type its base URL in the API base URL field below, give it a name here, and tap Add provider. After that it is one tap to fill its address in again. Providers are stored only on this device.

      No custom providers yet — add your first one above.

      Which endpoints work straight from this app? Any OpenAI-compatible endpoint that allows calls from a browser page (CORS) works here and in the installed app. If an endpoint refuses browser calls, Orbis says so plainly when you test it — that is the endpoint’s policy, not a wrong key.

      Your own server must allow browser calls (CORS): Ollama needs OLLAMA_ORIGINS=*, LM Studio needs “Serve local network / CORS” on, llama.cpp and vLLM allow it by default, and a GitHub Codespace port must be set to Public. Local servers need no real key.

      No model list? Some endpoints answer chat calls but offer no /models list to fetch. Orbis says so instead of calling it a failure — just type the model name by hand and tap Test connection.

      Paste any OpenAI-compatible base URL — it usually ends in /v1. You can paste it with or without https://, with a trailing slash, or even as the full address ending in /chat/completions or /models — Orbis cleans it to the base shape automatically. Local addresses like localhost:11434/v1 are kept as http, not forced to https.

      Stored only in this browser on this device, and sent only to the base URL above.

      Tap Fetch models to load the models your endpoint offers, then search them by name (the picker has a search box too) and pick one — or just type a model name by hand. If the endpoint answers the chat address but has no /models list, Orbis says so instead of calling it a failure.

      Saved combos

      A combo saves the base URL, key and model above under one name — like “My main endpoint” or “My Codespace”. Saving one never changes the connection you are using now; tap a combo when you want to switch to it. Combos are stored only on this device.

      Uses the base URL, key and model currently in the fields above. Saving with a name that already exists updates that combo.

      Getting a key

      1. Open your provider’s website, sign up, and find its API keys page.
      2. Create a key and copy it.
      3. Paste the provider’s base URL and the key above, add it under Your providers so it is saved, and tap Save.
      4. Tap Fetch models, search the list for the model you want, then tap Test connection — and ask the Assistant anything.

      Running your own server instead? It counts as a provider too — add its /v1 address above the same way. Local servers usually need no real key, and you can save the whole setup as a combo so switching back later is one tap in Settings or in the Assistant itself.
