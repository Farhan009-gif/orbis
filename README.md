# Orbis

A complete Class 9–10 study lab — **96 interactive experiments and visual lessons** in one app that works **fully offline**. Built as a single self-contained web app (pure HTML, CSS and JavaScript — no build step, no dependencies) and packaged as an Android app.

**Latest release: [v1.0](https://github.com/Farhan009-gif/orbis/releases/tag/v1.0)** — download the APK from the Releases page.

## Subjects

| Subject | Activities |
|---|---|
| Physics | 29 |
| Chemistry | 25 |
| Biology | 16 |
| Mathematics | 13 |
| Social Science | 7 |
| Computer Science | 6 |

## Every activity includes

- A realistic, interactive simulation or visualisation with live readings
- Aim, apparatus/materials and a step-by-step procedure
- Precautions/safety notes where the real practical needs them
- A formula/rule box and a recordable observation table
- A result section and a **"Check yourself"** 3-question quiz
- A closing **"The whole process, explained"** card — what happens and why, in plain words
- A **Voice guide** — listen to the whole experiment narrated (Helio voice, bundled as audio, so it works offline too)

## Highlights

- **Periodic table** — all 118 elements
- **Isotopes, Isobars & All the Atomic Essentials** — 21-set explorer with live average-atomic-mass calculation
- Real traced **world and India maps**
- Live search across the whole library, plus favourites, done-tracking and a recent list

## Study tools

- **Formula Vault** — every formula in the app, grouped by subject, searchable
- **Flashcards** — flip-card decks built from each experiment's key points
- **Glossary A–Z** — 74 key terms in one-line plain meanings
- **Exam Mode** — a timed 10-question mixed quiz with a per-subject score breakdown

## Assistant — offline by default, live if you want it

The built-in assistant answers offline with no setup. In **Settings** you can optionally connect your own **OpenAI-compatible endpoint** (any provider URL + API key + model — including your own saved custom providers and quick-switch combos). Your key stays **on your device only** and is sent only to the endpoint you typed. Everything else in the app works 100% offline; the internet is used *only* by the Live Assistant.

## Install

**Android:** download the APK from the [v1.0 release](https://github.com/Farhan009-gif/orbis/releases/tag/v1.0) and install it (Android 8.0+, minSdk 26). Coming from the older build? Uninstall it first — v1.0 uses a new signing key (one-time only; future updates install over it).

**Browser:** open `index.html` in any modern browser — that is the entire install. It also works offline once loaded.
